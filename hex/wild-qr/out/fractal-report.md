## Final geometry
- Micro-module: 2px  |  v1 symbol: 42px (21 modules)
- Dark padding/quiet ring: 3px each side (1.5 micro-modules)
- Parent-module cell: 48x48px  |  parent quiet zone: 4 modules (192px)
- Micro-tile "light" module colour: gray 130 (dark=0). Parent light
  cells + ground are pure white (255). The gray light is the key tuning knob:
  an inverted v1 tile is light-dominant in its symbol region, which is exactly
  where jsQR point-samples each parent module when decoding the box-downsample;
  gray light keeps every dark cell's centre below threshold so the parent
  decodes at BOTH 205px and 410px, while 130-vs-0 keeps the tile itself crisp.
- Full raster: 2352x2352px  |  preview: 410px  |  tiny: 205px
- Tile crop for close test: cell + 4-module dark quiet-zone pad.
